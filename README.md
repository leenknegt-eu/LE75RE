75 key, ortholinear, 60% hot swappable keyboard for MX style (RE) and Gateron KS-33 low profile switches (LRE).
Inspired by the Xiudi XD75RE which does not appear to be in regular production anymore.
Does not support lighting as the XD75 does.
Pin for pin compatible with the XD75, so QMK firmware should be cross-compatible.
